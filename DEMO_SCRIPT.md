# First-delivery walkthrough

1. Open the homepage at phone and laptop widths.
2. Switch the four hero dishes using the thumbnail controls.
3. Browse the signature-dish band.
4. Read the opening-hours badge and visit section.
5. Open Menu, Reserve and Dashboard to see the explicitly pending feature milestones.
