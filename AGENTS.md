# Project instructions

Read and follow `docs/AGENTS.md`, `docs/PRD.md`, and `docs/design.md` before changing this project. These are the authoritative requirements; the PRD controls behavior and the design document controls visuals.

The first delivery (M0 + M1) is complete. The current authorization completes M3–M9 in two sprints: M3–M6 customer flows, then M7–M9 dashboard, offline and verification. Preserve reference media and supplied documents. Keep unfinished milestones explicit in PROGRESS.md and REPORT.md. Run `npm run check` and commit each passing milestone before starting the next.
