# Project instructions

Read and follow `docs/AGENTS.md`, `docs/PRD.md`, and `docs/design.md` before changing this project. These are the authoritative requirements; the PRD controls behavior and the design document controls visuals.

The approved first delivery is M0 + M1 only. Preserve reference media and supplied documents. Keep unfinished milestones explicit in PROGRESS.md and REPORT.md. Run `npm run check` and commit each passing milestone before starting the next.
